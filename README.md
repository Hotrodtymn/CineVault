# CineVault

## Static movie-search interface

A browser-based movie search project built with HTML, CSS, and JavaScript. The repository includes a standalone `index.html` with a search interface.

> **Project type:** Portfolio project. This README describes the checked-in source rather than promising production functionality.

## Getting started

Open `index.html` in a browser. Depending on the JavaScript data source, live searches may require network access.
